Glossary

Minimum Allocation
To learn a skill in a tier N of a skill tree, you must have put N skill points into tier N-1.
Skill Point
Earned in play for heroic actions, combat sucess, clever roleplay, or milestones. Used to obtain new abilities
Skill Tree
Each core skill has a list of abilities separated into tiers; working up a tree unlocks more powerful abilities.
Core Skill
One of Physicality, Nature, Perception, Stealth, Personality, and Reasoning. A core skill has a particular die associated, from d4 - d12.
Physicality
A Core Skill focused on physical exertion, like sprinting, endurance, strength, or acrobatics. Combat focuses on heavier weapons.
Reasoning
A Core Skill focused on logic, investigation, and arcana. Combat focuses on magical implements.
Nature
A Core Skill focused on plants, animals, natural magic, and healing magic. Combat focuses on potions/decoctions/alchemical bombs.
Stealth
A Core Skill focused on various means of going undetected. Combat focuses on light weapons.
Personality
A Core Skill focused on charisma, persuasion, and insight into others. Combat focuses on finesse weapons.
Perception
A Core Skill focused on the senses and ability to vigilantly observe. Combat focuses on ranged weapons.
Ability
A modular, self contained mechanical ability found in the Skill Tree for the Core Skills.
Downtime
A period of extended rest (usually at least a day and night) during which you can rest and recover, as well as work on Projects, which might be learning new spells, building gadgets, improving weapons or armor, etc.
Project
A Downtime activity that involves making multiple DL rolls toward completion.
Scholar’s Token
A small, enchanted metallic token that signifies a reknowned researcher. Grants access to almost any library or other repository of knowledge.
Incapacitated
Status condition: At 0 HP, conscious, but too injured to move, defend yourself, take actions, or channel magic.
Subskill
A more specific/circumstantial form of a Core Skill, e.g., Stealth/Touch vs. Stealth/Sight. Each Core skill has 4-6 subskills defined in the system.
Fate Roll
A special d20 roll, usually made without modifiers, to capture moments of pure fate or chance. A Fate Roll Table (e.g., for Snake Eye Rolls) will usually dictate how to interpret the outcomes of this roll.
Arcane Toxicity
A cumulative effect from the process of casting magic, using magic equipment, or being healed by magic. See More.
Environmental Turn
The second turn of every combat round, during which environmental effects, lair actions, death fate rolls, surprise reactions, etc. take place. See: Initiative
Ability Roll
Any time you make a dice roll using one of the core dice (d4-d12). Ability checks, attacks, etc., all count as ability rolls.
Cover Area
A contiguous area of partial or full cover, like a wall, pillar, or hedge, of up to 20 ft in any dimension. Larger cover can be considered multiple Cover Areas at a GM’s discretion. Relevant for Combat Awareness
