# Overview

There are six skill trees to choose from in SWN, which cover the six primary ability areas. These core skills are

- {term}`Physicality`, which covers (in general) both strength and dexterity based abilities, 
- {term}`Nature`, which covers the natural world, flora and fauna, medicine, and alchemy, 
- {term}`Personality`, which covers social abilities, including persuasion, deception, and insight,
- {term}`Perception`, which covers degrees of noticing and detecting with the various senses, 
- {term}`Reasoning`, which covers logic and insight and the use of magic, and
- {term}`Stealth`, which covers all aspects of avoiding detection.

These core skills have some subdivisions, called {term}`Subskills <Subskill>` that are triggered circumstantially --- for example, Stealth checks make a distinction between which sense is primarily being obscured, whether sight, sound, smell, or touch. The subdivisions for each skill, and when those checks are relevant, are detailed in the [Skills Section](skills/core-skills.md).

## Ability Dice

In SWN, you have a die, one of (d4, d6, d8, d10, or d12) associated with each core skill. A d4 in a skill means it is "untrained," which means you cannot learn abilities in the trees for that core skill. At the start of a game, you will select one of three loadouts of ability dice: 

- **The Standard Array**: `d4, d4, d4, d6, d8, d10`. This is a well balanced array that focuses your efforts on three trained skills to start, with some breadth with one high (but not maximum) die. 
- **The Generalist Array**: `d6, d6, d6, d6, d6, d6`. The primary benefit of this array is that you are skilled in all core skills at the start of the game, and therefore have maximal skill tree flexibility. On the other hand, you have no die higher than d6, so your rolls will suffer for a while.
- **The Specialist Array**: `d4, d4, d4, d4, d10, 12`. This array focuses on quickly maximizing strength in two trees, useful for a build that relies heavily on only two trees. 

Every time your player levels up (every time you accumulate 10 skill points), you select one of your core dice, and upgrade it to the next die up, up to d12. 

## Skill Points 

Skill Points serve the roll of XP/experience in the game. You start off with a set number of Skill Points to use in building your character, and then earn more throughout your sessions. In general, it is expected that you will earn 1-3 Skill Points per session of play, but this can be reduced to, e.g., 1 per 2 sessions for tables that intend to play for an extended time and want slower progress toward high level. 

Skill Points are spent to aquire new **abilities** from the skill trees, for which each core skill has one. Most abilities cost anywhere from 1-3 skill points, meaning that you can expect to be able to learn a new skill ~roughly every session. 

## Skill Tree Abilities 

Abilities provide key, unique skills within the game, ranging from bonuses to standard ability rolls under specific (or general) circumstances, to major world-shattering ones at high level. To learn abilities in a certain skill tree, you must be "trained" in that skill, which means you have `>d4` allocated to it. 

Every ability in SWN has several key characteristics:

- The Tier, which is a form of "ability level". Tiers do not match 1:1 with player level, but define how much investment is needed in a particular tree to take abilities in that tier,
- The Cost, which is the number of skill points required to obtain the ability, 
- Prerequisites, which define any other abilities one must specifically obtain before acquiring a given ability. Prerequisites are not always in the same tree, and 
- Minimum Player Level, which for some abilities enforces the player be a certain level before an ability can be taken.  


Every Tier in a given skill tree defines a {term}`Minimum Allocation`. This is the number of skill points that must be invested in the level below a given tier before being able to invest in a given tier. This number is equal to the tier's level. For example, to invest in a Tier 2 ability in Stealth, you must have invested 2 points into Tier 1 in Stealth. To invest in a Tier 3 ability in Stealth, you would need to have invested 3 points in Tier 2 of stealth, an so on. 

This system represents the fact that more powerful abilities in a given discipline require more investment in that discipline to achieve, and creates a key character choice: invest heavily in fewer trees, becoming an expert, or invest broadly in all trees, becoming a generalist. There are advantages to both approaches, suiting different play styles and character backgrounds. 

### Example Ability 

Here is an example of what a single, "standard" ability might look like in one of the skill trees:

:::{dropdown} Stealth: Pickpocket (1 pt)
:open:
You've trained in the art of pickpocketing. You have +1 to Stealth/Touch rolls made to remove or place items from or on other individuals' person without their knowledge. 

- *Backstory hook*: Where did you learn this skill? Were you a desperate street urchin, a sly card gambler, a trained operative? 
:::

Backstory hooks are provided for many lower level abilities; these are designed to help you think about how your backstory might explain your current abilities — particularly useful for abilities you pick up during character creation.

## Player Level 
You level up in SWN every time you receive 10 consecutive skill points. You do not have to "save" them; new skills can be acquired at every {term}`Downtime`, in theory. Just keep a counter of skill points awarded, and whenever it hits 10, increment your player level and start over. 

Player level is significantly less important in SWN than other systems. Primarily, it is used by certain skills to prevent them from being taken by inexperienced characters. Typical things that accompany leveling up (e.g., more health, etc.) are obtained in the skill tree or at the player's discretion.
