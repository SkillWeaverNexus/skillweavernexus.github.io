# Core Skills

There are seven skill trees to choose from in SWN, which cover the six primary ability areas. These core skills are

- **Physicality**, which covers (in general) both strength and dexterity based abilities, 
 - **Nature**, which covers health, including mundane and magical healing, poisons and decoctions, and alchemical development, 
- **Personality**, which covers social abilities, including persuasion and deception,
- **Perception**, which covers degrees of noticing and detecting with the various senses, 
- **Reasoning**, which covers logic and insight and the use of magic, and
- **Stealth**, which covers all aspects of avoiding detection.
\end{itemize}

These core skills have some subdivisions that are triggered circumstantially --- for example, Stealth checks make a distinction between which sense is primarily being obscured, whether sight, sound, smell, or touch. The subdivisions for each skill, and when those checks are relevant, are detailed in the Skills chapter. Finally, the special tree contains more unique and involved abilities, which do not fit in the other categories. 

## Ability Dice

In SWN, you have a die, one of (d4, d6, d8, d10, or d12) associated with each core skill. A d4 in a skill means it is "untrained," which means you cannot learn abilities in the trees for that core skill. At the start of the game, you will have a d4 in 4/6 of your core skills. For two skills of your choice, you can allocate a d6 and a d8, representing some prior progression or competence in those abilities. 

Every time your player levels up (every time you accumulate 10 skill points), you select one of your core dice, and upgrade it to the next die up, up to d12. 

## Skill Tree Abilities 

Abilities provide key, unique skills within the game, ranging from bonuses to standard ability rolls under specific (or general) circumstances, to tree-defining abilities. To learn abilities in a certain skill tree (other than special), you must be ``trained'' in that skill, which means you do not have a d4 die for that skill. 

Every ability in SWN has several key characteristics:

- The Tier, which is a form of "ability level". Tiers do not match 1:1 with player level, but define how much investment is needed in a particular tree to take abilities in that tier,
- The Cost, which is the number of skill points required to obtain the ability, 
- Prerequisites, which define any other abilities one must obtain before acquiring a given ability. Prerequisites are not always in the same tree, and 
    \item Minimum Player Level, which for some abilities enforces the player be a certain level before an ability can be taken.  


Every Tier in a given skill tree defines a ``Minimum Allocation.'' This is the number of skill points that must be invested in the level below a given tier before being able to invest in a given tier. This number is equal to the tier's level. For example, to invest in a Tier 2 ability in Stealth, you must have invested 2 points into Tier 1 in Stealth. To invest in a Tier 3 ability in Stealth, you would need to have invested 3 points in Tier 2 of stealth, an so on. 

This system represents the fact that more powerful abilities in a given discipline require more investment in that discipline to achieve, and creates a key character choice: invest heavily in fewer trees, becoming an expert, or invest broadly in all trees, becoming a generalist. There are advantages to both approaches, suiting different play styles and character backgrounds.
