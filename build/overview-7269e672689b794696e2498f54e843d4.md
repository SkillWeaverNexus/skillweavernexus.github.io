# Overview

There are six skill trees to choose from in SWN, which cover the six primary ability areas. These core skills are

- {term}`Physicality`, which covers (in general) both strength and dexterity based abilities, 
 - {term}`Nature`, which covers health, including mundane and magical healing, poisons and decoctions, and alchemical development, 
- {term}`Personality`, which covers social abilities, including persuasion and deception,
- {term}`Perception`, which covers degrees of noticing and detecting with the various senses, 
- {term}`Reasoning`, which covers logic and insight and the use of magic, and
- {term}`Stealth`, which covers all aspects of avoiding detection.

These core skills have some subdivisions, called {term}`Subskills <Subskill>` that are triggered circumstantially --- for example, Stealth checks make a distinction between which sense is primarily being obscured, whether sight, sound, smell, or touch. The subdivisions for each skill, and when those checks are relevant, are detailed in the Skills chapter. Finally, the special tree contains more unique and involved abilities, which do not fit in the other categories.

In SWN, you have a die, one of (d4, d6, d8, d10, or d12) associated with each core skill. A d4 in a skill means it is "untrained," which means you cannot learn abilities in the trees for that core skill. At the start of a game, you will select one of three loadouts of ability dice:

## Skill Tree Abilities 

Abilities provide key, unique skills within the game, ranging from bonuses to standard ability rolls under specific (or general) circumstances, to tree-defining abilities. To learn abilities in a certain skill tree (other than special), you must be ``trained'' in that skill, which means you do not have a d4 die for that skill. 

Every ability in SWN has several key characteristics:

- The Tier, which is a form of "ability level". Tiers do not match 1:1 with player level, but define how much investment is needed in a particular tree to take abilities in that tier,
- The Cost, which is the number of skill points required to obtain the ability, 
- Prerequisites, which define any other abilities one must obtain before acquiring a given ability. Prerequisites are not always in the same tree, and 
- Minimum Player Level, which for some abilities enforces the player be a certain level before an ability can be taken.  


Every Tier in a given skill tree defines a {term}`Minimum Allocation`. This is the number of skill points that must be invested in the level below a given tier before being able to invest in a given tier. This number is equal to the tier's level. For example, to invest in a Tier 2 ability in Stealth, you must have invested 2 points into Tier 1 in Stealth. To invest in a Tier 3 ability in Stealth, you would need to have invested 3 points in Tier 2 of stealth, an so on. 

This system represents the fact that more powerful abilities in a given discipline require more investment in that discipline to achieve, and creates a key character choice: invest heavily in fewer trees, becoming an expert, or invest broadly in all trees, becoming a generalist. There are advantages to both approaches, suiting different play styles and character backgrounds. 

## Player Level 
You level up in SWN every time you receive 10 consecutive skill points. You do not have to "save" them; new skills can be acquired at every {term}`Downtime`, in theory. Just keep a counter of skill points awarded, and whenever it hits 10, increment your player level and start over. 

Player level is significantly less important in SWN than other systems. Primarily, it is used by certain skills to prevent them from being taken by inexperienced characters. Typical things that accompany leveling up (e.g., more health, etc.) are obtained in the skill tree or at the player's discretion.
