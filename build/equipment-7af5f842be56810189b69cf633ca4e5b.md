# Equipment

Equipment and kits are an important part of many builds. We've already discussed combat equipment; the table is reproduced here for completeness: 


| Tree | Category | Examples | 
| --- | --- | --- |
|Stealth	 | Light Weapons | Daggers, light crossbows, throwing knives|
|Physicality	 |Medium, Heavy Martial Weapons  |Shortswords, Longswords, Great Swords, Pikes/Halberds, heavy crossbows|
|Nature | Concoctions | Poisons, oils, alchemical bombs, potions |
|Perception | Ranged Weapons | Medium crossbows, heavy crossbows, long bows |
|Personality | Finesse Weapons | Rapiers, Dual Swords, Whip, Lasso | 
|Reasoning | Magic-tuned Weapons | Staffs, Wands, Orbs, Artifice |

The Tree listed indicates that the abilities needed to gain proficiency, expertise, and mastery in each weapon category are found in that tree. 

Things in SWN that have the `equipment` tag require proficiency to be used without the standard -10 penalty. 

```{note}
This is in contrast to the `item` tag, which generally does not require proficiency for use.
```

## Kits 

There are several kits available in the game. These are considered relatively mundane, potentially expensive, but not rare, and can be reasonably obtained if you do not start with one. The defined kits, which are `equipment`, are

 

| Kit | Tree | Description |
| --- | ---- | ----------- |
|Alchemy Kit | Nature | vials, beakers, pouches of alchemical ingredients, focused heat devices, and other compoents for the distillation of alchemical products. |
|Healer's Kit | Nature |  medical supplies such as bandages, salves, and torniquets, used to administer rapid, if modest, healing. |
| Trapping Kit | Perception | contains tools to facilitate the setting of tripwire alarms, rope/net traps, and mild magical protection. |
| Jeweler's Tools | Pereption | tweezers, magnifying glass, grinding stone, and reagents that reveal the nature of different gems and stones |
| Blacksmith's Tools | Physicality | Hammer, tongs, quenching oil. If desired, a mobile forge, which is unweildy. |
| Carpenter's Tools | Physicality | Basic tools for cutting, sanding, and joining wood. |
| Artifice Kit | Reasoning | a unique mix of tools and components used to construct gadgets, particularly with magical properties. |
| Mage's Kit | Reasoning | pouches of different natural ingredients that can be used as components in the casting of ritual spells. |
| Disguise Kit | Personality | makeup, masks, false hair, and other tools for adjusting one's appearance |

| Camouflage Kit | Stealth | darkened/foliage face paint, sound-dampening fabric wraps for weapons and armor, scent-masking compounds, special footwear that leaves minimal tracks, and light-absorbing dust. | 

Below are more detailed descriptions of each kit. 

### Forgery Kit (Personality)

A comprehensive collection of tools for creating convincing forgeries and falsifications. Contains various papers and parchments of different qualities, inks in multiple colors and compositions, seal stamps and wax of various types, tools for precise copying of handwriting and signatures, reference samples of common official documents, materials for aging documents artificially, and equipment for examining and authenticating existing documents.
Allows you to 
- Create convincing false documents (identification papers, permits, letters of introduction)
- Forge signatures and seals of officials or other important individuals
- Detect forgeries created by others through careful examination
Duplicate keys from wax impressions
Create counterfeit currency or valuable certificates
Open and reseal documents without detection
Age or weather documents to match established timelines
Create false credentials or authorizations

Game Mechanics:

Grants advantage on Personality/Deception checks when using forged documents
Allows for creating documents that can pass casual inspection (DL 15)
Can create documents that pass thorough inspection with higher DLs
Enables authentication checks to identify forgeries created by others
Allows for tampering with existing documents without obvious signs

This kit:

Has direct, practical applications in adventure scenarios
Provides specific mechanical benefits
Ties directly to the Deception subskill
Isn't setting-dependent (documents and seals exist in virtually all settings)
Creates interesting narrative opportunities
Is as concretely useful as lockpicks or traps in problem-solving

The Forgery Kit is a perfect fit for characters focused on social manipulation, infiltration, espionage, or any situation where presenting false credentials or documentation would be advantageous. It's simple to understand but offers depth in application, and it provides clear utility without requiring setting-specific assumptions.
